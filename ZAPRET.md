# Zapret

Плагин для Windows, который управляет **Zapret** — обходом DPI через
WinDivert. Это не прокси и не VPN: Zapret перехватывает пакеты на уровне
системы, поэтому ему нужны права администратора.

Поддерживаются два варианта бандла:

- **zapret2** (`winws2.exe`, Lua-стратегии, `blockcheck2`) — рекомендуется;
- **Flowseal v1** (`winws.exe`, `general*.bat`) — для совместимости.

## Что нужно

1. Windows 10/11 x64.
2. Бандл:
   - [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)
     для zapret2, либо
   - [Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube/releases/latest)
     для v1.
3. Распаковать содержимое бандла в каталог данных:

```text
%LOCALAPPDATA%\wireproxy-control\zapret\
```

Для zapret2 должны быть `zapret-winws\winws2.exe`, `zapret-winws\lua`,
`blockcheck\zapret2\blockcheck2.sh` и `cygwin\bin\bash.exe`.
Для Flowseal v1 — `bin\winws.exe`, `lists`, `general*.bat`.

Кнопка **«Папка Zapret»** создаёт и открывает эту папку.

## Как работает плагин

- Определяет движок: `winws2` или `winws`.
- Для zapret2 читает `preset2*.cmd`, для v1 — `general*.bat`.
- `.cmd`/`.bat` **не исполняются**: извлекаются аргументы движка.
- Создаёт службу Windows `wireproxy-zapret`.
- Установка/удаление/смена стратегии требуют UAC.
- После установки запуск/остановка идут из панели без повторного UAC.

## Автоматический подбор стратегии (zapret2)

Если в бандле есть `blockcheck2`, на вкладке Zapret доступна кнопка
**«Подобрать стратегию автоматически»**:

1. Запускается `blockcheck2.sh` через cygwin (UAC).
2. Проверяются стратегии на `www.youtube.com` и `discord.com`.
3. Из SUMMARY выбирается первая рабочая HTTPS-стратегия `winws2`.
4. Стратегия автоматически устанавливается в службу (второй UAC).
5. Прогресс и лог видны в карточке; при неудаче старая служба не
   затрагивается.

Ручные пресеты остаются как запасной вариант. `blockcheck2` может идти
несколько минут; это нормально.

## Порядок «напрямую → Zapret → VPN»

В карточке каналов есть переключатель **«Сначала напрямую»**. Когда служба
Zapret запущена:

- для домена, который по спискам должен идти через VPN, сначала делается
  короткий прямой HTTPS-проба-запрос;
- если напрямую (через Zapret) открылось — соединение идёт напрямую;
- если нет — используется WireGuard/VLESS, как раньше;
- результат кэшируется на 5 минут.

Если Zapret не запущен или домен принудительно закреплён за каналом
(«только VLESS»/«только WireGuard»), поведение не меняется.

Zapret не является прокси: он не умеет выбирать «этот запрос — напрямую, а
этот — через VPN». Поэтому «сначала напрямую» реализовано как проверка
прямого пути при активном Zapret, а VPN остаётся резервом.

## Ограничения

- Только Windows. На macOS плагин показывает предупреждение.
- Нужен WinDivert; антивирусы могут ругаться. Добавьте папку Zapret в
  исключения.
- UAC нельзя обойти: установка, смена стратегии и автоподбор его требуют.
- Автоподбор не запускается сам по таймеру — это осознанно, чтобы не
  показывать UAC в неожиданный момент. Кнопка запускает полностью
  автоматический поиск.
- Игровой фильтр Flowseal `%GameFilterTCP%`/`%GameFilterUDP%` подставляется
  пустым.
- Плагин не скачивает и не обновляет бандл автоматически.

## Безопасность

Аргументы стратегий передаются в PowerShell в base64, служба создаётся через
`sc.exe`, никакие `.bat` не исполняются. Служба называется
`wireproxy-zapret` и не трогает пользовательскую службу `zapret`.

## Лицензия

Zapret распространяется под MIT (bol-van, Flowseal), WinDivert — под своей
лицензией. Бандл не входит в `wireproxy-control`; пользователь скачивает его
отдельно.
